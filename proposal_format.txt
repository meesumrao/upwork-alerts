STYLE RULES
- Short and strong. Body (between "Hi," and "Meesum") should be about 60-110 words.
- Simple, confident, conversational English. Short paragraphs with blank lines between them.
- Use "..." for pauses. Never use em dashes.
- Don't mention any store names from the portfolio list inside the body; the list already shows them.
- Never invent clients, results, numbers or experience. Only use what's in my profile.
- If the job is a design / redesign / "make my store look better" / CRO job, offer to improve one section for free first.
- If it's a redesign or custom sections job, I can mention: "I'm currently redesigning AtlantaHobby.com with custom Shopify sections, and I can show you the work."
- If it's a dropshipping job, make it clear I do this every day and run a large dropshipping operation, and invite them to message me once.
- If it's a product listing / upload job with a deadline, commit to a fast, specific delivery time.
- If the budget type matters, I normally work hourly, but a fixed price for the complete project is fine too.
- I prefer written communication; mention it only if the client says they prefer chat over calls.
- No "Dear Hiring Manager", no long intros, no bullet points in the proposal.
